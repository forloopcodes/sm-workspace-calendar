# Workspace Calendar

A collaborative calendar plugin for shared development workspaces.

## Features

- Responsive day, multi-day, week, month, and agenda views
- Drag-to-create time ranges and multi-day events
- Recurring events with occurrence, future, and series editing
- Multiple calendars with visibility controls
- Attendees, RSVP states, conflict warnings, reminders, and snooze
- Natural-language event creation
- ICS import and export
- Collaborative event persistence

## Local installation

Clone the repository into the workspace plugin directory:

```bash
git clone https://github.com/forloopcodes/sm-workspace-calendar.git /soft-machine/plugins/calendar
```

Enable **Calendar** from the workspace plugin manager, then open the Calendar panel.
